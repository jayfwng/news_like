# 뉴스스냅

사람들이 많이 보는 뉴스를 **인스타그램처럼** 넘겨 보고, 모르는 **경제 용어**는 눌러서 바로 뜻을 보는 앱이에요.
서버 없이 GitHub만으로 돌아가요. 30분마다 GitHub Actions가 뉴스를 모으고, GitHub Pages로 앱을 띄워요.

## 화면 구성
- **경제 지표 줄**: 코스피, 코스닥, 원/달러, S&P500, 나스닥, 유가, 금, 비트코인. 이름을 누르면 무슨 지표인지 알려줘요.
- **스토리**: 오늘 TOP, 경제, 증시, 금리·환율, 부동산, 기업·산업, 정치, 사회, 국제, IT·과학. 누르면 분야별 상위 10개를 한 장씩 넘겨 봐요. 옆을 탭하면 넘어가고, 길게 누르면 멈추고, 아래로 쓸어내리면 닫혀요.
- **오늘 뉴스에 많이 나온 경제 용어**: 오늘 기사에 자주 나온 용어를 모아 보여줘요.
- **피드**: 화제성 순서예요. 여러 언론사가 함께 다룬 기사, 많이 본 기사일수록 위에 와요. 같은 사건은 한 장으로 묶이고, "다른 언론사 n곳 기사 보기"로 언론사별 제목을 비교할 수 있어요.
- **단어 찾기**
  - 경제 용어 사전에 있는 160여 개 낱말은 **파란 점선 밑줄**이 그어져요. 누르면 쉬운 풀이가 나와요.
  - 아무 글자나 **길게 눌러 선택**하면 "뜻 찾기" 버튼이 떠요. 사전에 없는 말은 위키백과에서 찾아줘요.
  - 지식백과, 표준국어대사전, 네이버 검색으로 바로 갈 수 있어요.
  - ☆를 누르면 **내 단어장**에 저장돼요.
- **저장**: 🔖로 저장한 뉴스를 모아 봐요. 저장한 뉴스와 단어장은 이 기기에만 남아요.
- 다크 모드, 홈 화면 설치(PWA), 오프라인 보기를 지원해요.

## 뉴스는 어디서 오나요
`scripts/sources.py`에 목록이 있어요.
- **언론사 RSS**: 연합뉴스, 조선일보, 동아일보, 한겨레, 경향신문, 매일경제, 한국경제, SBS, MBC, JTBC, 머니투데이, 서울경제 (경제 섹션 포함)
- **구글 뉴스 사이트 검색**: YTN, 중앙일보, KBS, 한국일보
- **많이 본 뉴스**: 구글 뉴스 주요 기사·분야별 헤드라인, 네이버 언론사별 많이 본 뉴스

앱에는 **제목, 사진, 짧은 요약만** 보여주고, 본문은 원문 링크로 이어져요. 기사 본문을 그대로 옮기면 저작권 문제가 생기기 때문이에요.
주소가 바뀌거나 막힌 피드는 그 피드만 건너뛰어요. Actions 실행 기록의 "뉴스 수집" 단계에서 피드별 성공·실패를 볼 수 있어요.

## 처음 한 번 설정하기 (5분)
1. 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 바꿔요.
2. 기본 브랜치에 이 코드가 있는지 확인해요. 30분마다 자동으로 도는 예약 실행은 기본 브랜치에서만 동작해요.
3. **Actions** 탭 → "뉴스 수집 및 배포" → **Run workflow**로 첫 수집을 돌려요. 2~3분 걸려요.
4. 끝나면 `https://jayfwng.github.io/news_like_insta/`에서 앱이 열려요.
5. 폰 크롬에서 열고 메뉴 → **홈 화면에 추가**를 누르면 앱처럼 쓸 수 있어요.

> 공개 저장소에서는 Actions와 Pages가 무료예요. 비공개 저장소는 무료 사용량 안에서 쓸 수 있는데, 30분마다 돌리면 한 달에 약 1,500분이 필요해요. 이 경우 `.github/workflows/news.yml`의 `*/30`을 `0 * * * *`(1시간마다)로 바꾸면 절반으로 줄어요.

## PC에서 실행해 보기
```bash
python scripts/crawl.py --out web/data/news.json
```
```bash
cd web && python -m http.server 8000
```
브라우저에서 `http://localhost:8000`을 열면 돼요. Python 3.10 이상만 있으면 되고, 따로 설치할 것은 없어요.

테스트는 이렇게 돌려요. 인터넷 없이 예시 피드로 확인해요.
```bash
python -m unittest discover -s tests -v
```
